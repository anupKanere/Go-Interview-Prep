# FAANG Interview Preparation - Go DSA Practice

## 🎯 Goal
Prepare for FAANG (Facebook, Amazon, Apple, Netflix, Google) and other big tech company interviews using Go programming language.

## 📅 Timeline: 3-4 Months

## 📚 Study Plan Overview

### Month 1: Foundation & Arrays
- Week 1-2: Arrays, Strings, Two Pointers
- Week 3-4: Hash Tables, Sliding Window

### Month 2: Data Structures
- Week 1-2: Linked Lists, Stacks, Queues
- Week 3-4: Trees, Binary Trees, BST

### Month 3: Advanced Data Structures
- Week 1-2: Heaps, Graphs (BFS/DFS)
- Week 3-4: Dynamic Programming Basics

### Month 4: Advanced Topics & Practice
- Week 1-2: Advanced DP, Greedy Algorithms
- Week 3-4: System Design Basics, Mock Interviews

## 🏗️ Directory Structure
```
├── 01-arrays-strings/          # Arrays, Strings, Two Pointers
├── 02-hash-tables/             # Hash Tables, Sliding Window
├── 03-linked-lists/            # Linked Lists
├── 04-stacks-queues/           # Stacks and Queues
├── 05-trees/                   # Binary Trees, BST
├── 06-heaps/                   # Heaps and Priority Queues
├── 07-graphs/                  # Graph Algorithms

├── 10-system-design/           # System Design Basics
├── templates/                  # Go coding templates
├── tests/                      # Test files
├── resources/                  # Study resources
└── mock-interviews/            # Practice interviews
```

## 🎯 Daily Practice Schedule
- **Weekdays**: 2-3 hours (1 hour theory + 1-2 hours coding)
- **Weekends**: 4-5 hours (2 hours theory + 2-3 hours coding)
- **Daily**: 3-5 problems (mix of easy, medium, hard)

## 🚀 Getting Started
1. Review the study plan in `STUDY_PLAN.md`
2. Start with `01-arrays-strings/` directory
3. Use templates in `templates/` for consistent coding style
4. Practice with tests in `tests/` directory

## 📈 Progress Tracking
- Keep track of solved problems in each directory
- Note time complexity and space complexity
- Record common patterns and techniques
- Practice explaining solutions out loud
