# 🚀 Getting Started with FAANG Interview Prep

## 📋 Quick Start Guide

### 1. **Setup Environment**
```bash
# Run the setup script
go run setup.go

# Initialize Go module (if needed)
go mod init faang-interview-prep
```

### 2. **Start Your Journey**
```bash
# Begin with Arrays & Strings
cd 01-arrays-strings

# Copy a template for your first problem
cp ../templates/problem_template.go two_sum.go

# Edit the problem and implement your solution
# Run tests
go test -v two_sum.go
```

### 3. **Daily Practice Routine**
- **Morning**: 1 hour theory review
- **Afternoon**: 1-2 hours coding practice
- **Evening**: 30 minutes review and planning
