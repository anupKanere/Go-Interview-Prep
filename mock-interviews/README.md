## 🚀 Mock Interview Practice

### 📝 Coding Interview Template

#### **Problem 1: Arrays & Strings (15-20 minutes)**
```
Problem: Two Sum
Difficulty: Easy
Time Limit: 15 minutes

Given an array of integers nums and an integer target, 
return indices of the two numbers such that they add up to target.

Example:
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
```

#### **Problem 2: Data Structures (20-25 minutes)**
```
Problem: Group Anagrams
Difficulty: Medium
Time Limit: 20 minutes

Given an array of strings strs, group the anagrams together.

Example:
Input: strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

#### **Problem 3: Advanced Topics (15-20 minutes)**
```
Problem: Longest Substring Without Repeating Characters
Difficulty: Medium
Time Limit: 15 minutes

Given a string s, find the length of the longest substring 
without repeating characters.

Example:
Input: s = "abcabcbb"
Output: 3
```

### 🏗️ System Design Interview Template

#### **Problem: Design a URL Shortener**
```
Requirements:
- Shorten long URLs
- Redirect short URLs to original URLs
- Handle 100M URLs per day
- 99.9% uptime
- 5-year data retention

Questions to discuss:
1. What's the scale?
2. What are the main features?
3. What's the API design?
4. How do you handle the database?
5. How do you handle caching?
6. How do you handle load balancing?
7. What are the trade-offs?
```

#### **Problem: Design a Chat System**
```
Requirements:
- Real-time messaging
- 1M concurrent users
- Message history
- Group chats
- Online status

Questions to discuss:
1. What's the architecture?
2. How do you handle real-time communication?
3. How do you store messages?
4. How do you handle scaling?
5. How do you handle failures?
```

### 🎭 Behavioral Interview Template

#### **Leadership Questions**
1. **Tell me about a time you led a team**
   - Situation: What was the context?
   - Task: What was your responsibility?
   - Action: What did you do?
   - Result: What was the outcome?

2. **Tell me about a time you had to make a difficult decision**
   - What was the situation?
   - What options did you consider?
   - How did you decide?
   - What was the result?

#### **Problem-Solving Questions**
1. **Tell me about a time you solved a complex problem**
   - What was the problem?
   - How did you approach it?
   - What was your solution?
   - What was the result?

2. **Tell me about a time you failed**
   - What happened?
   - What did you learn?
   - How did you improve?

#### **Teamwork Questions**
1. **Tell me about a time you worked with a difficult team member**
   - What was the situation?
   - How did you handle it?
   - What was the outcome?

2. **Tell me about a time you had to give feedback**
   - What was the situation?
   - How did you approach it?
   - What was the result?
