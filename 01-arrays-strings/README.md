## 💡 Tips for Success

1. **Start with brute force**: Get a working solution first
2. **Optimize step by step**: Improve time/space complexity
3. **Handle edge cases**: Empty inputs, single elements
4. **Practice explaining**: Be ready to explain your approach
5. **Time yourself**: Aim for 20-30 minutes per medium problem
