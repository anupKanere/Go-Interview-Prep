# 📚 FAANG Interview Study Plan - 3-4 Months

## 🎯 Target Companies
- **FAANG**: Facebook (Meta), Amazon, Apple, Netflix, Google
- **Other Big Tech**: Microsoft, Uber, Airbnb, Twitter, LinkedIn, etc.

## 📅 Monthly Breakdown

### Month 1: Foundation & Core Algorithms
**Goal**: Master basic data structures and algorithms

#### Week 1-2: Arrays & Strings
- **Topics**: Arrays, Strings, Two Pointers, Sliding Window
- **Problems**: 20-25 problems
- **Focus**: Time/Space complexity, edge cases
- **Key Patterns**: 
  - Two pointers (left/right, fast/slow)
  - Sliding window
  - String manipulation

#### Week 3-4: Hash Tables & Advanced Arrays
- **Topics**: Hash Tables, Maps, Set operations
- **Problems**: 20-25 problems
- **Focus**: Hash table optimization, collision handling
- **Key Patterns**:
  - Frequency counting
  - Two sum variations
  - Anagram problems

### Month 2: Linear Data Structures
**Goal**: Master linked lists, stacks, and queues

#### Week 1-2: Linked Lists
- **Topics**: Singly/Doubly linked lists, cycle detection
- **Problems**: 15-20 problems
- **Focus**: Pointer manipulation, memory management
- **Key Patterns**:
  - Two pointers (fast/slow)
  - Reversal techniques
  - Merge operations

#### Week 3-4: Stacks & Queues
- **Topics**: Stack, Queue, Deque, Priority Queue
- **Problems**: 15-20 problems
- **Focus**: LIFO/FIFO operations, monotonic stacks
- **Key Patterns**:
  - Valid parentheses
  - Monotonic stack
  - BFS/DFS foundations

### Month 3: Trees & Advanced Structures
**Goal**: Master tree algorithms and graph basics

#### Week 1-2: Binary Trees
- **Topics**: Tree traversal, BST operations
- **Problems**: 20-25 problems
- **Focus**: Recursive thinking, tree properties
- **Key Patterns**:
  - DFS (pre/in/post order)
  - Tree validation
  - Path problems

#### Week 3-4: Heaps & Graphs
- **Topics**: Min/Max heaps, Graph traversal (BFS/DFS)
- **Problems**: 20-25 problems
- **Focus**: Heap operations, graph representation
- **Key Patterns**:
  - Top K problems
  - Shortest path
  - Connected components

### Month 4: Advanced Topics & Practice
**Goal**: Master DP, system design basics, and interview practice

#### Week 1-2: Dynamic Programming
- **Topics**: 1D/2D DP, memoization, tabulation
- **Problems**: 15-20 problems
- **Focus**: Pattern recognition, state transitions
- **Key Patterns**:
  - Fibonacci variations
  - Knapsack problems
  - LCS/LIS problems

#### Week 3-4: System Design & Mock Interviews
- **Topics**: System design basics, behavioral questions
- **Focus**: High-level design, scalability
- **Practice**: Mock interviews, time management

## 📊 Daily Schedule

### Weekday Routine (2-3 hours)
- **Hour 1**: Theory review and new concepts
- **Hour 2**: Code 2-3 problems (mix of easy/medium)
- **Hour 3**: Review solutions, optimize code

### Weekend Routine (4-5 hours)
- **Hours 1-2**: Deep dive into complex topics
- **Hours 3-4**: Code 4-5 problems (medium/hard)
- **Hour 5**: Mock interview or system design

## 🎯 Problem Distribution
- **Easy**: 40% (build confidence)
- **Medium**: 45% (core interview problems)
- **Hard**: 15% (advanced topics)

## 📈 Weekly Goals
- **Week 1-4**: 80-100 problems
- **Week 5-8**: 80-100 problems
- **Week 9-12**: 80-100 problems
- **Week 13-16**: 60-80 problems + mock interviews

## 🔄 Review Schedule
- **Daily**: Review previous day's problems
- **Weekly**: Review all problems from the week
- **Monthly**: Comprehensive review of all topics

## 📝 Progress Tracking
- Keep a log of solved problems
- Note time taken for each problem
- Record common mistakes and learnings
- Track improvement in problem-solving speed

## 🎯 Success Metrics
- Solve 300+ problems total
- Average 20-30 minutes per medium problem
- Can explain solutions clearly
- Comfortable with system design basics
- Ready for mock interviews

## 🚀 Go-Specific Focus Areas
- **Memory Management**: Understanding Go's garbage collection
- **Concurrency**: Goroutines and channels (for system design)
- **Performance**: Time/space complexity optimization
- **Testing**: Writing comprehensive test cases
- **Code Style**: Clean, readable, maintainable code

## 📚 Additional Resources
- **Books**: Cracking the Coding Interview, Elements of Programming Interviews
- **Platforms**: LeetCode, HackerRank, CodeSignal
- **Practice**: Pramp, InterviewBit, AlgoExpert
- **System Design**: Designing Data-Intensive Applications, System Design Interview

Remember: Consistency is key! 🚀
